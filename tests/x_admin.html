Our teams

The names, colours and order used across the whole site: the Links page, Match Centre, phone team bar, TV banners and page titles. Change a name here and it changes everywhere once you press Save. Up to six teams.

Add a teamSearch the RFU list, then choose the league it plays in this season.

A name typed into a link (friendlyName=) still wins over the name here, so links you shared earlier keep showing what they showed. Links made from the Links page and the link builder no longer carry a name, so they follow this list. Teams that are not on this list, such as opponents, keep the name the RFU gives them.

Paired screens

Screens set up with the quick setup page (open /setup on a TV). Each has its own ID. Kick out sends a screen back to the setup code: a rotating screen notices within about 5 minutes, other pages at their next refresh (every 10 minutes on match days, hourly otherwise). The Usage page shows when each screen was last seen.

Data sources

Where the site gets its information.

England Rugby website as a back-upWhen the RFU data service has no league table, ground or team list, the site asks the englandrugby.com website instead. Turn this off to use the data service only: a table or ground it cannot supply is then left blank. Check the RFU web page row on the Usage page first.

Today the data comes from the RFU data service. The England Rugby website is only used as a back-up when the data service has nothing. Check the “RFU web page” row on the Usage page before turning the back-up off.

Club PIN and access

Who can see the club pages: the club PIN and how long a sign-in lasts.

How long a PIN sign-in lastsAfter this many days a device is asked for the club PIN again. Devices already signed in keep the length they were given; changing the PIN signs everyone out at once. Anyone can also use Sign out (bottom of the Links, Documentation and Admin pages).
